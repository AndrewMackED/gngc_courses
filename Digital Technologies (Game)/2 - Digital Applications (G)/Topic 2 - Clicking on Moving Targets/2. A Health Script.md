# 2. A Health Script
So we're going to be making a **Health Script**. We're going to want to assign this script to any object that we will want to take damage.

Let's take a think about the kinds of objects that might need to take damage:
- Humanoid Enemies - **CharacterBody3D** 
- Random Movable Objects - **RigidBody3D**
- Random Non-Movable Objects - **StaticBody3D**

So we want to make our health script generic enough to be added to any of these objects.
Let's take a quick look at how all these Node Types are organised in Godot...
![[body inheritance.png]]
You can see that all of those types of bodies are inherited from **PhysicsBody3D** 

They are also technically children of **CollisionObject3D** too, but we don't really want to use this for **Area3D**s, since you can't deal damage to a trigger area

We're going to make our Health script start with `extends PhysicsBody3D`, since we're going to want to use it on various different classes that inherit from it.

```gdscript
extends PhysicsBody3D
class_name Health

@export var hp : int = 3

func take_damage(dmg : int):
	hp -= dmg
	if hp <= 0:
		queue_free()

```

Let's break that down!
- We've made sure that we've set it as `extends PhysicsBody3D` so we can add it to any body we need to
- I've given it the `class_name Health` so I can easily check "if body has health" basically. 
- I've given it a variable for `hp` to keep track of how many hit points the object has. I've set a default value of 3 hp, but you can also see that I've exported the variable so I can put it on a variety of different objects, and I can change their individual HP in the editor 😊
- Finally, I've given it a take_damage function that I can call
	- It comes with a variable so I can change the amount of damage the body will take (more for bigger gun maybe)
	- If the HP hits zero (or less) then we'll destroy the object!

Go right ahead and give the script to any bodies that you want to take damage!

## Adjusting the Gun.gd script
Now we have our health script, we need to look for it when we shoot stuff!
All you have to do is add this function to our current script (just at the end of it)

```gdscript
func _unhandled_input(event):
	if event.is_action_pressed("fire") and is_colliding():
		var body = get_collider()
		if body is Health:
			body.take_damage(1)
```

Note: Do make sure that you have the "fire" event action set up in your project settings.

So this is fairly straightforward, but there are a couple elements worth explaining
- Firstly, `_unhandled_input` is for any input events that you want to be looking at, that aren't currently being used by a UI or something
	- For example, if you crack open a pause menu, when you click on something, it will get priority to use the mouse click, and you won't end up shooting something at the same time.
- Then we need to check if the event is "Fire" and if the raycast is actually colliding with something 
	- Right now we're ignoring the fact that players might shoot thin air, at the moment it doesn't count. If you want to add an ammo system, you'll need to split out those conditions into separate nested statements.
- Create a local variable to hold the collider that we're looking at, call it body
- Check if the body has a health script attached, and if it does, deal it some damage.
