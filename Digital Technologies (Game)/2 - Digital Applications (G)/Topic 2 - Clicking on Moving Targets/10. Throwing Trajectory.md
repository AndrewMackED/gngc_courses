## 2. Trajectory Script
To make our trajectory functional, our approach is to throw an imaginary version of our grenade and track the path it takes. We will measure the position of the imaginary grenade at multiple time intervals and save these points then draw a line that connects these points.

We need to attach this script to our TrajectoryLine node:
```gdscript
extends MeshInstance3D

 
@export var maxPoints = 150      
@export var timeStep = 0.02    

# Dynamic throwing attributes from the grenade manager
@export var throwForce = 8.0   
@export var throwAngle = 40

#Based on grenade weight
@export var item_mass = 1  

@onready var camera: Camera3D = $"../../Camera3D"

func _process(_delta):
	var launch_position = global_position
	
	var aim_direction: Vector3 = -camera.global_transform.basis.z
	aim_direction = aim_direction.rotated(camera.global_transform.basis.x, deg_to_rad(throwAngle))
		
	var calculated_speed = throwForce / item_mass
	var launch_velocity = aim_direction * calculated_speed
	
	update_trajectory(launch_position, launch_velocity)

func update_trajectory(startPosition: Vector3, startVelocity: Vector3):
	var gravity = ProjectSettings.get_setting("physics/3d/default_gravity") * ProjectSettings.get_setting("physics/3d/default_gravity_vector")
	
	var points: Array[Vector3] = []
	var currentPosition = startPosition
	var currentVelocity = startVelocity
	var spaceState = get_world_3d().direct_space_state

	for i in maxPoints:
		points.append(currentPosition)
		
		var nextPosition = currentPosition + currentVelocity * timeStep
		var nextVelocity = currentVelocity + gravity * timeStep
		
		var query = PhysicsRayQueryParameters3D.create(currentPosition, nextPosition)
		var result = spaceState.intersect_ray(query)
		if not result.is_empty():
			points.append(result.position)
			break
			
		currentPosition = nextPosition
		currentVelocity = nextVelocity

	draw_line(points)

#Render the trajectory line
func draw_line(points: Array[Vector3]):
	mesh.clear_surfaces()
	if points.size() < 2: return
	mesh.surface_begin(Mesh.PRIMITIVE_LINE_STRIP)
	for point in points:
		mesh.surface_add_vertex(to_local(point))
	mesh.surface_end()
```
There is a LOT going on in this script so let's spend some time breaking it down:
### Variables
```gdscript
@export var maxPoints = 150      
@export var timeStep = 0.02    

# Dynamic throwing attributes from the grenade manager
@export var throwForce = 8.0   
@export var throwAngle = 40

#Based on grenade weight
@export var item_mass = 1  

@onready var camera: Camera3D = $"../../Camera3D"
```
- `maxPoints` is how many points we will have in our trajectory line, this changes how long our line is
- `timeStep` is the time interval between measurements of the imaginary grenade
- `throwForce` is the force that we use to throw our grenade, this value needs to match the value we have set in our grenade manager script
- `throwAngle` is the angle that we throw our grenade at, this needs to match the angle value we have set in our grenade manager script
- `item_mass` is the mass of our grenade, this needs to match the mass property of our grenade rigid body
- `camera` references the camera that our player character uses **Make sure to properly reference your camera here**.
### Process
```gdscript
func _process(_delta):
	var launch_position = global_position
	
	var aim_direction: Vector3 = -camera.global_transform.basis.z
	aim_direction = aim_direction.rotated(camera.global_transform.basis.x, deg_to_rad(throwAngle))
		
	var calculated_speed = throwForce / item_mass
	var launch_velocity = aim_direction * calculated_speed
	
	update_trajectory(launch_position, launch_velocity)
```
In our `process` function, we are doing the following:
- `launch_position` gets the current position from where we are throwing
- `aim_direction` gets the direction that the character is facing by using the camera direction and the following line rotates the direction according to the `throwAngle`
- `calculated_speed` is how fast we throw our grenade
- `launch_velocity` calculates the velocity using the direction and speed
- Then we call `update_trajectory` passing in our `launch_position` and `launch_velocity` as arguments
### Update Trajectory
Let's look at what our update trajectory function is doing section by section
```gdscript
func update_trajectory(startPosition: Vector3, startVelocity: Vector3):
```
Looking at the variables we declare in our function:
```gdscript
var gravity = ProjectSettings.get_setting("physics/3d/default_gravity") * ProjectSettings.get_setting("physics/3d/default_gravity_vector")
	
	var points: Array[Vector3] = []
	var currentPosition = startPosition
	var currentVelocity = startVelocity
	var spaceState = get_world_3d().direct_space_state
```
- `gravity` gets the project settings for our gravity so it can properly simulate the throw
- `points` stores the points of our trajectory line
- `currentPosition` stores where our imaginary grenade currently is
- `currentVelocity` stores the speed and direction our grenade currently has
- `spaceState` let's us use godot's physics engine to make calculations

Next we have our loop:
```gdscript
for i in maxPoints:
		points.append(currentPosition)
		
		var nextPosition = currentPosition + currentVelocity * timeStep
		var nextVelocity = currentVelocity + gravity * timeStep
		
		var query = PhysicsRayQueryParameters3D.create(currentPosition, nextPosition)
		var result = spaceState.intersect_ray(query)
		if not result.is_empty():
			points.append(result.position)
			break
			
		currentPosition = nextPosition
		currentVelocity = nextVelocity
```
- This loop runs `maxPoints` times
- Each time it runs:
	- We add our imaginary grenade's current position to our list of points
	- `nextPosition` uses our current position and velocity to calculate where our imaginary grenade will be after our time step
	- `nextVelocity` uses our current velocity and gravity to calculate the velocity of our imaginary grenade after our time step
	- `query` sets up a raycast between our current position and next position
	- `result` stores the result of using the using the raycast to find intersections, if the result is empty this means that our trajectory line won't intersect with anything if we extend it to include our next position.
	- If our result is not empty then we want our line to stop since it doesn't make sense to let our trajectory line go through objects, so we add the collision point as the end as the last point of our line and call `break` to stop our loop
	- Finally we make our current position equal to our next position and our current velocity equal next velocity to move our imaginary grenade forward.
Finally our function calls `draw_line()` passing in our points.
### Draw Line
The draw line function is the more straightforward part of our script
```gdscript
func draw_line(points: Array[Vector3]):
	mesh.clear_surfaces()
	if points.size() < 2: return
	mesh.surface_begin(Mesh.PRIMITIVE_LINE_STRIP)
	for point in points:
		mesh.surface_add_vertex(to_local(point))
	mesh.surface_end()
```
- `mesh.clear_surfaces()` resets the line, clearing any old points we had on there
- `if points.size() < 2: return` checks if there is less than two points in our trajectory line, if so we can't draw a line so it just exits our function with return
- `mesh.surface_begin(Mesh.PRIMITIVE_LINE_STRIP)` creates a new geometric surface in our mesh which will be our line
- Then we loop through the points and add them to the line
- Finally we end the surface to complete the drawing of our line
And with that we can now see the trajectory of our grenade throws!

## 3. Toggling Visibility
Our player isn't going to need to see the throwing trajectory all the time, just when they go to throw their grenade. So we are going to add a way to toggle the visibility of the trajectory line.
### Make a new Input 
-   Go to your project settings
-   Select Input Map
-   In the “Add New Action” field type “aim_grenade” and press Add
-   Then you will see the new aim_grenade action
-   Click Add event beside the new action
-   Press the key that you want to use to throw your grenade and press OK to save it
### Add Toggling Function
In our Grenade Manager script add a reference to our trajectory line:
```gdscript
@onready var trajectory = $Trajectory
```
Then add the following two lines in the unhandled_input function in the Grenade Manager script:
```gdscript
if event.is_action_pressed("aim_grenade"):
		trajectory.visible = !trajectory.visible
```
This toggles the visibility between on and off when we press our aim grenade button.
Let's test it out:
![[Trajectory Toggle Demo.gif]]
Now our trajectory line toggles on and off. You change the color and transparency of your immediate mesh material to change the look of the trajectory line.
