# A basic script for testing a Raycast
There's a lot you can do with a raycast!
- Clicking on interactable objects (as explored in the 3D Player Interactions guides)
- Checking if an object is within direct line of sight
- Firing a gun
- Commanding troops in an RTS or similar

We're probably going to be building this into a First-Person Shooter game later down the track, but for now, we're going to just find out some basic information for anything that happens to come across the middle of our screen.

Before we start programming, please add a **label** to your scene as well. I've just added it next to the crosshair. This is going to be printing the name of anything that we look at!
![[my example.png]]

Also, right click on it and give it "Access By Unique Name" for the script to find it a little easier

Ok, let's look at the script now:
```gdscript
extends RayCast3D

@onready var info_label = %InfoLabel

func _physics_process(delta):
	if is_colliding():
		infoLabel.text = get_collider().name
	else:
		infoLabel.text = ""

```

So that's my script! It's very simple, it's just designed to hover over objects, and show you the name of them on the Label :)

![[Animation.gif]]

It's nothing special, but it's a good start! We're going to be building on top of this in the coming weeks, and honestly it's not a bad debugging tool.

## A little more permanent feedback
This is a good test, but obviously we're probably not going to implement this in-game (although there are games that do this sort of thing)

Let's add a little colour change to the crosshair if we're looking at a collidable object!
It's a nice detail to give the crosshair a little flavour if something is shootable, and if you keep track of your crosshair in FPS games, they'll often increase in size when shooting, etc. It's a good place to implement some feedback.

We're going to need to make our Crosshair Rect a unique name, so right click on it and select "Access By Unique Name"

```gdscript
extends RayCast3D

@onready var info_label = %InfoLabel
@onready var crosshair = %Crosshair

var blank_color : Color = Color("00000080") 
var highlight_color : Color = Color("FF000080")

func _physics_process(delta):
	if is_colliding():
		info_label.text = get_collider().name
		crosshair.color = highlight_color
	else:
		info_label.text = ""
		crosshair.color = blank_color
		
```

Give that a test, it should change the crosshair colour when you're looking at a shootable object! (technically, when something has a collider!)
