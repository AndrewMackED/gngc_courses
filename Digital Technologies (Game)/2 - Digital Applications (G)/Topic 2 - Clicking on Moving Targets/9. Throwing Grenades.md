# Throwing Grenades
Now that we have a functional grenade we want to make it actually usable by our player.
## 1. Setting Up Our Nodes
The first step is to add a Node3D as a child of the Head of our Player. I named this node GrenadeManager.

![[Grenade Manager Node Structure.png]]

This position of this node will be the spawn point for our grenades so move it around to find a spot you are happy with. For mine I move it to the left side of my player body so that my player shoots with their right hand and throws grenades with their left hand.

## 2. Implementing the Throw
We need to add a new input for throwing our grenades:
-   Go to your project settings
-   Select Input Map
-   In the “Add New Action” field type “throw_grenade” and press Add
-   Then you will see the new throw_grenade action
-   Click Add event beside the new action
-   Press the key that you want to use to throw your grenade and press OK to save it

Now that we have our input we can move to our script. 

Create a new script attached to the GrenadeManager with the following code:
```godot
extends Node3D
  
@export var grenadeScene : PackedScene

@onready var camera: Camera3D = $"../Camera3D"

var throwForce = 8.0
var throwAngle = 40

func _unhandled_input(event: InputEvent):
	if event.is_action_pressed("throw_grenade"):
		var grenade = grenadeScene.instantiate()
		get_tree().current_scene.add_child(grenade)
		grenade.global_position = global_position
		
		var forward_dir: Vector3 = -camera.global_transform.basis.z
		if throwAngle != 0.0:
			var right_axis = camera.global_transform.basis.x
			forward_dir = forward_dir.rotated(right_axis, deg_to_rad(throwAngle))
		
		grenade.apply_central_impulse(forward_dir * throwForce)
```
There are a couple of things going on in this script:
&emsp; Starting from the top we have a throw force and throw angle variable, which controls how hard we throw and the trajectory of our throw. I found that not having the throw angle made the throwing look unnatural since the grenade just went straight forward.
&emsp; Our unhandled input function listens for inputs, and if those inputs match the throw_grenade input that we set up in the previous step then it throws a grenade.
&emsp; Grenade throwing works by instantiating a grenade at our GrenadeManager position, then the script calculates the direction that we are facing, rotates that direction by the throw angle, and then applies a central impulse to our grenade in the calculated direction.

Since we are using another PackedScene, go to the Inspector for the Game Manager and load our grenade scene into the Grenade property (like we did for the explosion effect).

## 3. Grenade Adjustments 
Now that we have implemented the base functionality I encourage you to modify your implementation to tailor it to your game.
Here are some ideas of changes you could make to your grenade, I've implemented the first two for you:
### Vacuum Grenade: 
**Description**: Creates a small black hole effect, rather than pushing objects away when it explodes it draws objects in

![[Vacuum Grenade Demo.gif]]

This one is really straight forwards we just need to modify one line in our explode function. Changing:
```godot  
body.apply_central_impulse(blastDirection * explosionForce)
```
To be 
```godot
body.apply_central_impulse(-blastDirection * explosionForce)
```
We are making the blast force negative so objects go in the opposite direction
> You might want to consider how you should change the visual effects, it doesn't make much sense for the explosion effect to spray outwards if the blast is drawing things in
### Landmine Grenade:
**Description**: The grenade explodes when an enemy comes in contact with it, like a land mine.

![[Landmine Grenade Demo.gif]]

To do this we would have our grenade check the group of bodies that it is colliding with and see if they are in our "targets" group. If they are then explode.
We would update our `physics_process` function to be:
```godot
func _physics_process(delta):
	var bodies = get_colliding_bodies()
	for b in bodies:
		if b.is_in_group("targets"):
			explode()
```
> You just need to make sure that you are using the correct group name for the enemies

### Sticky Grenade:
**Description**: Makes the grenade stick to an enemy, this could be done by detecting when the grenade hits an enemy and reparenting our grenade to that enemy and turning off the effects of gravity on the grenade. 

### Dispersion Grenade:
**Description**: The grenade deals varying amounts of damage depending on how close objects are to it. 

This one could be done with having multiple, different sized blast areas that each deal their own damage, objects that are closer would be dealt damage more times and therefore take more damage. Applying different amounts of force depending on which blast area an object is in could also be cool!

### Limited Grenades:
**Description**: Currently our grenades can be spammed, if you want the grenades to feel like a valuable resource you can implement a cooldown for throwing grenades or a limit for the number of grenades on each level. This would involve changes mostly in our Grenade Manager.

### Decoy Grenade:
**Description**: Draws nearby enemies towards the grenade when it explodes. If you have enemies that use a state machine to patrol and attack the player you can have the explosion trigger a state change to attack the grenades position.

### Molotov Grenade:
**Description**: Leaves a temporary burning area after exploding like a molotov cocktail. Enemies that walk over this area take damage.

**Hopefully you got some ideas or inspiration from this section to apply to your game.**
