## The Goal
So what do we want it to do? Take a look at this screenshot below, which shows me pointing at Suzanne's ear. There are honestly two versions of this script; one that's a little simpler but less nice, and a slightly more complex one that's worth doing.

The more basic version of a function like this would just apply the force to the centre of the object you're shooting. But looking at the image below, clearly if we shot Suzanne's ear, we should expect her to spin around right?

So our function  is going to need to do a few things:
- Work out the vector that we're shooting from
- Find the exact point that we're shooting at
- Apply a force to that *exact* location, with the force being applied at our shooting direction's vector

## Adding Force to the Gun Script

```gdscript
extends RayCast3D

@onready var info_label = %InfoLabel
@onready var crosshair = %Crosshair

@export var hit_force : float = 5

var blank_color : Color = Color("00000080") 
var highlight_color : Color = Color("FF000080")

func _physics_process(delta):
	if is_colliding():
		info_label.text = get_collider().name
		crosshair.color = highlight_color
	else:
		info_label.text = ""
		crosshair.color = blank_color
		
func _unhandled_input(event):
	if event.is_action_pressed("fire") and is_colliding():
		var body = get_collider()
		if body is Health:
			body.take_damage(1)
		if body is RigidBody3D:
			apply_force(body)
			

func apply_force(body: RigidBody3D):
	var shoot_direction = -global_transform.basis.z
	var impulse = shoot_direction * hit_force
	var offset = get_collision_point() - body.global_position
	body.apply_impulse(impulse, offset)
```

Let's break down the new additions:
- We're creating a new exported variable, `hit_force`. We can adjust the amount of force we're applying in the editor if we want to tweak it!
- We've added a new IF statement under the `fire` input, to check if the object we've hit is a rigidbody. If it is, we'll run our new `apply_force` function
- Obviously the `apply_force` function is new!
	- We're getting the shoot direction by getting the raycast's global transform basis, on a negative Z (the direction the raycast is currently set up to face)
	- The impulse force is calculated by multiplying the shoot direction by the `hit_force` variable
	- We find the offset point from the target object to the collision point. This is needed for the `apply_impulse` function! (see the Godot Definition below to read up more about the `position` parameter where we're sending our `offset` variable)
	- Then we tell the body to apply that force!

The Godot Docs definition for "Apply Impulse"

>**apply_impulse**(`impulse`: [Vector3](https://docs.godotengine.org/en/stable/classes/class_vector3.html#class-vector3), `position`: [Vector3](https://docs.godotengine.org/en/stable/classes/class_vector3.html#class-vector3) = Vector3(0, 0, 0)) [](https://docs.godotengine.org/en/stable/classes/class_rigidbody3d.html#class-rigidbody3d-method-apply-impulse)
>Applies a positioned impulse to the body.
>
>An impulse is time-independent! Applying an impulse every frame would result in a framerate-dependent force. For this reason, it should only be used when simulating one-time impacts (use the "_force" functions otherwise).
>
>`position` is the offset from the body origin in global coordinates.
