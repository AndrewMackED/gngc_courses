## Hit Effects
Let's build our first effect.
1. Create a new scene, just make it a Node3D, and then we're going to add a GPUPartcles3D as a child
2. All inside the GPU Particles, do ALL OF THIS
	1. Set Amount to 15
	2. Lifetime to 2s
	3. One Shot to True
	4. Explosiveness to 1
	5. Process Material - Create a new one, make the following settings
		1. Velocity
			1. Direction > y = 5
			2. Spread = 20
		2. Collision
			1. Mode = Rigid
			2. Friction = 0.5
			3. Bounce = 0.7
	6. Draw Passes
		1. Pass 1
			1. Select a mesh of your choice, I chose a PrismMesh
			2. Adjust the size to something small, I made mine 0.05m on all axes
			3. Create a material for the Material

Before we do anything else, we're going to give it a little controller script. This is going to go on the Node3D.

```gdscript
extends Node3D

@onready var gpu_particles_3d = $GPUParticles3D

func _ready():
	gpu_particles_3d.emitting = true

func _on_gpu_particles_3d_finished():
	queue_free()
```

This script handles a couple boring things:
- It makes the emission start when this effect is initialised
- It removes the effect from the game once it's finished
- DONT FORGET TO CONNECT THE SIGNAL ON THE PARTICLE EFFECET
	- I should note, if you don't connect the signal, you might never notice. But your computer might. If someone shoots 1000 times in your level, there are an extra 1000 Node3Ds and finished particle effects hanging around for no reason. Do some tidying!

## Adding it to the Gun Script
Ok, let's make it appear when we shoot things! Time to edit the `gun.gd` script.
I'm just going to give you pieces from here, be careful to read where they go!

We're going to create a variable where we can assign our particle effect system to the script. This goes up the top below our other variables.
```gdscript
@export var hit_effect : PackedScene
```

Inside `_unhandled_input`, we're going to add this onto the end of the function (after the `if body is RigidBody3D` is all sorted)
```gdscript
		var effect = hit_effect.instantiate()
		get_tree().current_scene.add_child(effect)
		effect.global_position = get_collision_point()
```
These few lines are going to create a copy of the effect in our scene, and set it's position to the collision point the Raycast is colliding with.

It's actually that easy! The worst part was definitely creating the effect, right?
