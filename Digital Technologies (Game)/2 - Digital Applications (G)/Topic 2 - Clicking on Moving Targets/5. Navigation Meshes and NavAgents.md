# 5. Navigation Meshes and NavAgents

Ok, so let's get started implementing Navigation Agents. This is going to take a few steps, so let's outline the overall process first;
1. Design your level (or at least a basic start of a level)
2. Implement the Navigation Mesh
3. Create a basic Navigation Agent to move around the map

## 1. Create your level
My level isn't too wild here, but I did want to make sure that I include a ramp!
![[my_level.png]]

A few notes about this:
- Try to keep your level design contained to a single node and it's children. This is going to be relevant shortly! 
- I have found a trick for making ramps easily!
	- Make a CSGPolygon3D, and remove one of the top points, that will give you a triangular prism!
	- Adjust the remaining points to your liking, mine are as follows:
		- (0, 0), (0, 5), (15, 0)
		- For those of you interested, that means that the angle of the ramp is about 30°, I'm about to explain why that's relevant
- Keep a few things in mind, like the **default agent settings**, see these here:
- ![[NavAgentDefaults.png]]
- So you can see here, by default, agents can only go up steps of 0.25m and ramps of less than 45°. 
- You can absolutely change these settings, but these are relatively standard for a reason, and unless you're implementing [goats](https://www.youtube.com/watch?v=RG9TMn1FJzc) as your enemies, I'd use these as a guide for level design.

## 2. Implement the Navigation Mesh
This is a fairly easy step, as long as you kept your node management organised.

- Create a new **NavigationRegion3D** for your navigable area
- Move all of your map layout to be a **child** of the new Nav Region node
- On the NavigationRegion3D, create a new NavigationMesh
- Click Bake NavigationMesh at the top of the scene viewer.
The gif below demonstrates the process, you're complete once the blue layer appears over the navigable areas of the map!

## 3. Create a basic the Navigation Agent

### Script
The script has a bit going on, so please take a look at it first, and then we can break it down:

```gdscript
extends CharacterBody3D

@onready var nav_agent = $NavigationAgent3D
var movement_speed = 5.0
var gravity = ProjectSettings.get_setting("physics/3d/default_gravity")

var i = 0
@export var points : Array[Vector3] 

func _ready():
	if points.size() > 0:
		nav_agent.target_position = points[i]
		
func _physics_process(delta):
	if not is_on_floor():
		velocity.y -= gravity * delta

	if not nav_agent.is_navigation_finished():
		var next_path_pos = nav_agent.get_next_path_position()
		
		var dir = global_position.direction_to(next_path_pos)
		dir.y = 0
		dir = dir.normalized()
		
		velocity.x = dir.x * movement_speed
		velocity.z = dir.z * movement_speed
	else:
		velocity.x = 0
		velocity.z = 0
		if points.size() > 0:
			i = (i + 1) % len(points)
			nav_agent.target_position = points[i]
	
	move_and_slide()

```

### Set up the Points
The script above is set up a little differently to how we did it in the 2D State Machine game, the points are set up in this script to just be Global Coordinates.

So once you've assigned the script to the movable enemy, head over to the Points variable at the top of it's inspector, and assign the points that you'd like the enemy to move to! 

As a hint, try to set the Y coordinates accurately, otherwise you'll run into some oddities. If you take a look at mine below, I've included a gif of how the enemy behaves, and also the coordinates of the points.
