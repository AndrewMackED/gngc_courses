# 8. Grenades
In this section we are going to be implementing throwable grenades to our game. There is a lot of customisation you can do with an explosive like this to suit your game so we’ll be looking at implementing a basic version that you can adapt.

This grenade system only requires you to have implemented up to the “Particle Effects!” page.
## 1. Setting Up Our Grenade Scene
Let's start by making a new scene for our grenades:
1.  Create a new scene with a RigidBody3D as the root node.
    
2.  Add a CollisionShape3D to serve as the body of our grenade.
    
3.  Add a MeshInstance3D for the physical appearance of the grenade.
    
4.  Add an Area3D for our blast area, and give it a CollisionShape3D as a child node.
    
5.  Finally, add a timer to our grenade.

The Node structure should look like this: (Note that I’ve renamed the nodes to reflect their purpose in the scene)
![[Grenade Node Structure.png]]
Let’s break down what each component is doing:

-   Grenade (RigidBody3D): This allows us to use physics on our grenade which will be useful for throwing.
    
-   Body (CollisionShape3D): Gives the structure to our grenade letting it collide with objects and the floor.
    
-   GrenadeModel (MeshInstance3D): This is the physical appearance of our grenade.
    
-   Timer: This allows us to delay the explosion of our grenade after we throw it.
    
-   BlastArea (Area3D): This is the area that is affected by our grenade explosion.
    
-   BlastAreaCollision (CollisionShape3D): This lets us determine which objects are within our blast area so we can damage them.

Now let’s set up the grenade model:

1.  In the grenade’s CollisionShape3D choose a shape. I chose a SphereShape3D for mine, and I set the radius to 0.25 m
    
2.  In the MeshInstance3D I selected a SphereMesh to match my collision shape and set the radius to 0.25 m and the height to 0.5 m. If you want your grenade to have any designs make sure to adjust the material.
    
3.  Next we want to set up the CollisionShape3D within our Area3D, a SphereShape3D makes the most sense for the shape of our blast area. I chose a radius of 1 m for mine but this will depend on how strong you want to make your grenade explosions.

## 2. Making Our Grenade Functional
Now that our node structure and grenade model are set up we now have to implement the functionality of our grenade.

The first thing we need to do is to turn on Contact Monitor in our RigidBody3D and set the Max Contacts Reported to be 1 or greater:
![[Contact Monitor.png]]
Next we need to attach the following script to our RigidBody3D node:

```gdscript
extends RigidBody3D

@onready var blastArea = $BlastArea
@onready var timer = $Timer

var delay = 1
var damage = 2

func _ready():
	pass

func _physics_process(delta):
	if get_contact_count() > 0 and timer.is_stopped():
		timer.start(delay)

func _on_timer_timeout():
	explode()

func explode():
	var bodies = blastArea.get_overlapping_bodies()
	for body in bodies:
		if body.has_method("take_damage"):
			body.take_damage(damage)
	queue_free()
```
We also need to make sure that we connect our Timer's timeout signal to the script. 
Let's break down what our script is doing:
The get_contact_count() detects if our grenade hits anything, and when it does it starts our timer. Once our timer ends the script calls our explode function. When our grenade explodes it gets all of the objects in the blast area and deals damage to the object if it has a take_damage function. After the grenade is done dealing damage it calls queue_free to delete itself.

**Customisations (Optional):** 
With this script there is already a lot of customisation we can do at this stage depending on how you want your grenade to function. If you want the grenade to explode upon contact you can call explode() from the physics_process function instead of timer.start().

If you want the grenade timer to start from when you throw the grenade you can call timer.start() in the ready function. And of course you can change the damage variable to adjust the potency of your grenade.

## 3. Explosion Effect
If we test our grenade by placing it in our scene beside objects that get one shot by the grenades damage we can see that our grenade is functional but pretty underwhelming. Without the objects despawning we would have no way of knowing the grenade exploded.

![[Grenade Demo No Effects.gif]]

Similar to our gun hit effect we want to use particle effects to make it clear that our grenade is exploding. To do this we can reuse the work we’ve done with our hit effect by:

1.  Go to our hit effect scene and copy the root node
    
![[Copy Hit Effects.png]]

2.  Make a new scene and select “Paste From Clipboard” to create the root node
    
![[Paste Node From Clipboard.png]]

3.  This will create a copy of our hit effect scene, save this scene as “explode_effect”.
    
4.  To make the effect more suitable for an explosion you can adjust the GPUParticles3D properties. I changed the amount to be 35, and increased the Spread to 180 and the Initial Velocity to min 3.0 and max 7.0.  Play around with the GPUParticles to get an effect that you’re happy with.
	1. To find the Spread and Intiial Velocity go to GPUParticles3D Inspector, find the Process Material and click on the ParticleProcessMaterial to expand the properties. Spread and Initial Velocity can be found in the Velocity section.
    

Now we have to add the effect when our grenade explodes. To do this we add this line at the top of our grenade script:
```gdscript
@export var explosionEffect : PackedScene
```
This is the same method we used to add our hit effect to our gun.
Now we need update our explode() function to add the effect. Replace your current explode() function with this updated one: 
```gdscript
func explode():
	var effect = explosionEffect.instantiate()
	get_tree().current_scene.add_child(effect)
	effect.global_position = global_position
	
	var bodies = blastArea.get_overlapping_bodies()
	for body in bodies:
		if body.has_method("take_damage"):
			body.take_damage(damage)
	queue_free()
```
In the Inspector for our Grenade we will see our PackedScene property that looks like this:

![[Packed Scene for Explosion.png]]

We need to assign our explode_effect scene to this property by either dragging our explode_effect.tscn into this field or clicking on the \<empty>, clicking load and loading our explode_effect scene.

Now if we test out our scene we can see our explosion effect:
![[Grenade Demo With Effects.gif]]

This is good and all, but if we don’t deal enough damage to destroy an object it looks a bit dull:
![[Grenade Demo With Effect Not Destorying.gif]]

So we want to implement a knockback effect like we did with our bullets to give the explosion feedback.

## 4. Explosion Feedback

Luckily adding the knockback is straight forward. We first need to add an explosion force variable to our grenade script. Put this line at the top of your script with your other variables:
```gdscript
var explosionForce = 5
```
Then update the explode() function to be:
```gdscript
func explode():
	#Effect
	var effect = explosionEffect.instantiate()
	get_tree().current_scene.add_child(effect)
	effect.global_position = global_position

	var bodies = blastArea.get_overlapping_bodies()
	for body in bodies:
		if body.has_method("take_damage"):
			body.take_damage(damage)
		if body is RigidBody3D:
			var blastDirection = global_position.direction_to(body.global_position)
			body.apply_central_impulse(blastDirection * explosionForce)
	queue_free()
```
In this new script, after we apply damage to a body we apply a force to the object in the direction from the grenade to the body. This creates an exploding outward effect.
![[Grenade Demo With Effect and Feedback.gif]]

Now our grenade is functional and visually effective! Next we'll look at throwing our grenades.
