### Approaching a new feature:
There are lots of ways you can tackle creating new features in Flask. The recommended way I will usually do it for any new **forms**, is in the following order:
1. Setting Up
2. Creating the Form (HTML / frontend)
3. Handling the Form Data (Python / backend)

So without further ado, let's get into it.

## 1. Setting Up
Let's do a couple things to begin with!
- Create the HTML file for the template
- Create the route and function
- Create a navigation link to the new route in the base.html

### Create the HTML file
This one's easy!
Make a new html file inside your `templates` folder, call it `create_user.html`
Fill it with this blank template inheritance code
```html
{% extends "base.html" %}

{% block title %} Create New User {% endblock %}

{% block content %}
<h1>Create New User</h1>
{% endblock %}
```

### Create the route and function
We're just going to set up a new function for ourselves, we'll fill in all the details shortly.
I'm going tto make sure that this route has both the GET and POST methods enabled, since it's going to be used for a **form**

```python
@app.route("/create_user", methods=["GET", "POST"])
def create_user():
    return render_template("create_user.html")
```

Make sure you add this function *directly below your index function*

### Add the link the Base.html's navigation bar
This is well worth doing now to make your life easier while testing! Head over to your `base.html` and update your navigation bar to look like this:

```html
<div class="topnav">
	<a href="{{url_for('index')}}">Home</a>
	<a href="#new_job">New Job</a>
	<a href="{{url_for('create_user')}}">New User</a>
</div>
```

Now, from any page of your website you should be able to access the Home/Index page and the create_user page!

## 2. Creating the Form (HTML)
Here, we're going to need to create the HTML form where users will be entering their data to register themselves in the system.

Let's check our Database structure to see what we're storing:
![[Robotics Job Logger ERD.png]]

Let's go through them in order and work out how we're going to populate each of the fields:
- ID - Autogenerated by the database, we don't need to worry about it
- Name - Entered by the user in the form, probably a regular text field
- The Student ID and School Email is an interesting one, 
	- If we get the Student ID from the user, we can build their email address from the Student ID
	- Let's just ask for their student ID in a text input, and we'll sort out the email address with *string manipulation* on the backend

Here's my form! Just replace the "Content" block with this inn your create_user html file

```html
{% block content %}
<form method="POST">
    <label for="name">Name</label><br>
    <input id="name" name="name">

    <br><br>

    <label for="student_id">Student ID</label><br>
    <input id="student_id" name="student_id">
    <br><br>

    <button type="submit">Create User</button>

</form>
{% endblock %}
```

A couple notes around this:
- The Label is a great tool for making sure you HTML forms are properly labelled, in both a user visibility sense, but it's also something that screen readers look for, so very good practice.
- There are lots of different ways you can arrange form elements, this is just one of the easiest!

## 3. Handling the Form Data (Python)
Now we have our physical form, we need the Python side of the system to handle the form inputs when the user clicks "Create User".

We already created the basic version of the route that displays the html template, now we're going to expand on it to handle the user inputs. **Make sure you *replace* the existing code with the code below**

```python
@app.route("/create_user", methods=["GET", "POST"])
def create_user():
    if request.method == "POST":
        new_user = User(
            name = request.form["name"],
            student_id = request.form["student_id"],
            email = request.form["student_id"] + "@schoolsnet.act.edu.au"
        )
        
        db.session.add(new_user)
        db.session.commit()
        
        return redirect(url_for("index"))
    return render_template("create_user.html")
```

The code above does the following when the user submits the form:
- Creates a new `User` object, with the name, student_id, and build the student's email address based on the student_id
- Adds the new `User` object to the database
- Redirects the user to the home page of the website once they're done.
